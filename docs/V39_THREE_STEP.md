# FIELDNOTES V3.9 · 三步地理摄影离线预览

预览入口（正式发布完成后）：
https://jasonz0829vip.github.io/fieldnotes-travel-zine/preview/v39/

1. 从手机拍照或导入已有照片，所有照片均仅在本机进行渲染。
2. 选省、市、区县，自动判断局部真实街道包是否存在：已有包直接继续、未下载可选择下载或跳过、没有包时使用行政边界。现有局部精细地图只有陵水、上海黄浦、西安雁塔，不代表整座城市覆盖。不识别街道门牌号，无法断言精确拍摄地。
3. 一次绘制第一组六款，下一组六款使用现成 V3.7 第 07—12 套绘图预设，第三次返回第一组并复用其画布预览；选定后仍可高清导出。

独立存储：本版 PWA 的 Cache Storage 使用 fn39- 前缀，与 V3.8-P1 的 fn38p1- 前缀隔离。点击设置 → 地图管理，可查看或删除地区包，或者清理本版本离线文件。浏览器 HTTP 缓存可能另占空间，完全移除可能需清理网站数据；删除缓存不删除系统相册的作品。

避免重复开发：继续使用已集成的原生 Canvas、Mapbox Vector Tile/PBF、PWA、现有行政区几何和 V3.7 构图；没有引入第二套重型地图/渲染框架，测试使用成熟 Playwright + GitHub Actions。

隔离与验证：旧根首页、/preview/v38-p1/ 不作修改。独立 V3.9 Chromium 自动验收包括照片导入、黄浦局部地图按需下载、12 款渲染与缓存循环、基础地图退化、离线重启、独立缓存清理和 ZIP 构建。
这些不等于中国普通移动网络 iOS/Android 首次安装或安卓微信真实保存相册已通过，后两项仍待真机确认。
