# FIELDNOTES · V3.8+ 结构化迭代路线（2026-10-18）

## 不可改变的产品边界
- 家人用中国普通手机即可制作：不要求 VPN、ChatGPT 账号、连接 QLS/3070、安装远程控制、端口映射或配置代理。
- **本地离线是基本可用性，联网只是可选画质增强**，不得降低基础操作。
- QLS 与 RTX3070 是平等、可替换节点，执行同一份脚本与构建产物，不人为划分职责。
- 保护原照片主体、准确地图来源，不能伪造街道、拍摄 GPS、照片对象。
- 已验收的苹果保存流程与安卓微信保存路径必须分别回归；旧 V3.6 稳定版不改动。
- 优先成熟开源组件；禁止按 Star 数或增加模板数量伪装产品进度。

## P1 · 国内普通网络首次使用与真机交付 — 下一个优先项
必须先完成可交付而非复杂服务器架构：
1. 选择中国正常网络可访问的 HTTPS 静态文件分发路径；不需要 QLS/3070 作为运行时服务器，不需要公网端口、24 小时在线。
2. 用一台未配置 VPN 的国产安卓手机和一台 iPhone，从普通移动网络打开并完成首装（网页/PWA 或经评估的轻量安装式方案）。
3. 彻底关闭 → 飞行模式 → 重新启动 → 本地导入 → 已预装街道区域一键生成三版 → 保存到相册。
4. 验证**安卓微信中真实保存成功**，不是按钮提示或模拟器弹窗；苹果路径无回退。
5. 地区包按需要制备、发布，避免把全国道路数 GB 硬塞进所有手机；无包地区始终显示真实行政边界。
6. 不上传私人照片、GPS 轨迹与工程到公共服务器。保留失败记录、测试机型、浏览器及结果。

**完成定义：** 国内无代理真机实测的上传→选地点→出图→相册保存闭环，断网之后仍能用；失败场景明确、不会假装成功。

## P2 · 高质量差异化构图 — P1 后集中验收
- 不再以 12 个参数变体充当 12 个作品；先打造 **3 种审美及版式明显不同**的精品模式。
- 拍摄点街网/水道/海岸/山地数据与照片场景相适配，英文地名、小坐标、红点及比例尺；不存在大型外挂米色地图版头。
- 成熟主体分割模型（优先研究 MediaPipe）自动避开人物、动物与重要建筑；保留手动保护兜底，未经允许不重绘主体。
- 同一张照片的三种候选在布局、地图表达、字体体系和融合位置上可被肉眼明显区分；“再来一组”需去重，不只换透明度。
- 使用两张已登记的陵水参考照片（酒店与白鲸）和用户提供的参考视觉做 A/B 作品验收，不把技术指标充当审美通过。
- 保留完整离线功能和 Android/iOS 保存回归。

## P3 · 可选在线 AI — 只有价值成立才接入
- 比直接上传照片给 AI 写指令更方便、或原图保真/地图精度显著更可控，才值得接入。
- 国内网络稳定可达、成本明确、照片是否上传有清晰授权；用户可以完全不使用。
- QLS/RTX3070 可互替，但远程算力服务绝不能成为家人手机的使用前提。
- 不为使用插件/模型本身增加复杂网络配置。

## 代码与验收规则
- 每个阶段单独目录/分支，先自动化与真机证据，后并入稳定版。
- 先完整交付 P1，再扩展 P2；不要出现多个模块各完成 10% 的情况。
- 每次发布标记版本、覆盖地区、离线边界、第三方地图署名、已测设备、未测场景。
